เติมเครดิต
  • 1 บาท = 1 เครดิต (ตั้งค่าได้ AUTO_TOPUP_RATE)

  • Commission ค่าเริ่มต้น: 5% (ตั้งค่าได้)
  • จาว: คืนเครดิตทั้งคู่ ไม่หัก Commission

การเก็บข้อมูลและกันพัง

📁 ไฟล์ข้อมูล

  • users.json — UID / ชื่อ / เครดิต
  • profit.json — ยอดกำไร Commission
  • order_state.json — state ออเดอร์
  • round_backups/ — backup รายรอบ

🔒 กัน Duplicate

  • Message ID cache — กัน LINE retry
  • Slip ID — กัน double top-up
  • STATE_LOCK — กัน race condition
  • TTL 10 นาที ล้าง message cache

⚡ Performance

  • ThreadPoolExecutor — push ไม่บล็อก
  • LINE reply timeout 4 วินาที
  • Profile fetch cooldown 120 วิ
  • Retry LINE API 2 ครั้งอัตโนมัติ
